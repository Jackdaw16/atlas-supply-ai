# Incident Escalation Policy

Incident types are Delay, QualityIssue, ShortShipment, DamagedGoods, and Other. Incident statuses are Open, InProgress, Resolved, Closed, and Cancelled.

An Open incident can move to InProgress. An Open or InProgress incident can move to Resolved, and a Resolved incident can move to Closed. Incidents that are not Resolved or Closed can be Cancelled.

Use existing application queries or MCP tools for live incident records. This policy does not describe notification workflows or service-level agreements.
